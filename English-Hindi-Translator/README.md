# English to Hindi Translator

A beginner-friendly Python GUI project that translates English words and sentences into Hindi using a predefined dictionary.

## Technologies
- Python
- Tkinter
- Dictionary
- String manipulation
- Exception handling

## Run
Open the terminal in this folder and run:

```bash
python translator.py
```

## Files
- `translator.py` — main GUI application
- `dictionary.py` — English-Hindi word dictionary
- `README.md` — project documentation
